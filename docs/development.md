# 开发记录

## 2026-11-04 · v0.1.0

本项目来自参赛者与 AI 的真实讨论：选择 Linux CLI 电脑助手，通过可配置模型 API，支持文件编辑、终端任务和桌面操作。参赛者明确要求独立实现，不包装 agent-desktop，并在每个可运行版本完成后上传 GitHub。

### 本次实现

1. 建立 Python 包和命令行入口、API 配置与兼容 Chat Completions 的传输层。
2. 实现模型/工具执行循环、文件 SHA256 冲突检测和备份、限时 Shell，以及 AT-SPI 语义控件适配。
3. 添加自动测试、CI、使用文档与可选本地对话记录。

### 当前验证证据

- 当前开发环境：Arch Linux / KDE / Wayland，Python 3.14.9。
- `--help`、`doctor`、模块编译通过；GI 的 Atspi 2.0 可加载。
- 本地自动测试通过，含模拟 HTTP 服务的文件创建/读回流程。
- 尚无真实模型 API 联调结果，也未实际操作用户桌面验证。不能将模拟测试描述成真实 AI 控制电脑成功。
