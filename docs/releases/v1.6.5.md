更新 Linux 对话状态栏，并同步构建 Windows / Linux 下载包。

- 任务运行时按 Ctrl+D 返回「选择对话」，顶部持续显示任务状态。
- 待审批任务置顶并以黄色标出，显示待审批数量和对应对话编号；进入对应对话后查看操作并批准或拒绝。
- 对话重新排序后，顶部编号随之更新；仅选择对话不会批准操作。
- 区分执行中、思考计时、等待资源、等待审批、排队、正在停止、已完成、失败和已取消。
- 顶部最多显示 4 条记录，优先保留待审批和运行中的任务，剩余位置显示最近结束的结果。
- 返回主菜单后隐藏顶部状态栏，后台任务继续运行。

下载：
- Windows：`desk-agent-windows-x64.zip`，解压运行 `desk.exe`，可用包内 `install.ps1` 安装。
- Linux：`desk-agent-linux-x64.tar.gz`，解压运行 `./desk`，可用包内 `install.sh --setup-path` 安装。需要 glibc 2.35+ 和系统运行库，详见包内说明。
- 校验：`SHA256SUMS.txt`。

包内不包含个人模型配置、API 密钥或对话。
