简化 MCP 配置导入。

- 支持直接粘贴多行 JSON 配置。
- 支持查看和保存远程 MCP JSON 示例。
- 文件路径支持外层引号，方便复制含空格的路径。
- JSON 语法错误显示行号和字节位置。
- 配置为空、缺少 mcpServers 或服务名称重复时给出明确提示。
- 导入失败保留已有配置，配置只存储在本机。

Simplified MCP configuration import.

- Paste multiline JSON directly.
- View or save a remote MCP JSON example.
- Quoted configuration file paths are accepted.
- JSON syntax errors include line and byte positions.
- Clear messages for empty configurations, missing mcpServers, and duplicate names.
- Failed imports preserve existing configuration. Settings stay local.
