Improved chat and tool approval interaction.

- Type / in an empty composer to open actions immediately. Esc closes the popup.
- Tool approvals support arrow navigation and default to Cancel.
- Linux background chat preserves an unfinished draft during approval.
- Unified the desk code title across terminal sizes.
- Windows chat reads console key events for immediate action menus.
- Added PTY coverage for draft restoration, previews, approval, and popup cancellation.
