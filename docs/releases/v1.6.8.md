更新双语文档和一行安装方式，Windows / Linux 同步发布。

- README 改为中英双语，并用第一人称说明项目用途和使用方式。
- Linux 支持一行安装：
  `curl -fsSL https://raw.githubusercontent.com/Milorgs/desk-agent/main/install-linux.sh | sh`
- Windows PowerShell 支持一行安装：
  `irm https://raw.githubusercontent.com/Milorgs/desk-agent/main/install-windows.ps1 | iex`
- Windows 引导脚本适配 Release ZIP 的根目录结构。
- Release 包内的 Linux / Windows 说明同步提供一行安装命令。

包内不包含个人模型配置、API 密钥或对话。
