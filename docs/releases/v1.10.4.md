提升文本搜索与命令执行的效率。

- 文本搜索改为整块查找，没有匹配的大文件不再逐行重复扫描，常见搜索快 3–24 倍。
- 搜索结果的路径、行号和行内容保持不变，并增加行号回归检查。
- 执行命令时等待间隔逐步放宽，长命令期间的唤醒次数减少约 95%，短命令仍即时返回。

Faster text search and lighter command waits.

- Text search scans each file once instead of rescanning the rest of the file per line; common searches are 3–24x faster.
- Search results keep the same paths, line numbers and text, with a new line-number regression check.
- Command waits back off gradually, cutting wakeups during long commands by about 95% while quick commands still return at once.
