Windows 10/11 x64 与 Linux x86_64 同步发布。

- 设置页面返回后重新整理画面，避免旧菜单堆叠；保存结果、未配置模型和连接错误会保留在返回后的页面。
- 修复设置子菜单收到 Ctrl+D 后反复刷新的问题；数字选项前后的空格不再影响选择。
- 删除对话时释放对应后台进程、管道和任务名额；运行中的操作会停止，反复创建和删除不再累积已删除的对话资源。
- Linux 顶部状态栏和对话列表显示待执行需求数量；没有排队需求时减少重复状态检查。
- 保留现有实时思考计时、中英文界面、数字菜单和本次运行内的对话记录方式。

下载：
- Windows：`desk-agent-windows-x64.zip`，解压运行 `desk.exe`，可用包内 `install.ps1` 安装。
- Linux：`desk-agent-linux-x64.tar.gz`，解压运行 `./desk`，可用包内 `install.sh --setup-path` 安装。需要 glibc 2.35+ 和系统运行库，详见包内说明。
- 校验：`SHA256SUMS.txt`。

包内不包含个人模型配置、API 密钥或对话。
