Windows 10/11 x64 与 Linux x86_64 同步发布。

- 修复 Windows 路径分隔符不同导致正常文件被误判为工作目录外的问题。
- 包含数字菜单、多对话后台任务、OpenAI / Anthropic 接口和 MCP 工具导入。
- 包含 C++ 工具定义缓存、API 连接复用和增量编译优化。

下载：
- Windows：`desk-agent-windows-x64.zip`，解压运行 `desk.exe`，可用包内 `install.ps1` 安装。
- Linux：`desk-agent-linux-x64.tar.gz`，解压运行 `./desk`，可用包内 `install.sh --setup-path` 安装。基于 Ubuntu 22.04 构建，依赖 glibc 2.35+ 和系统运行库，详见包内说明。
- 校验：`SHA256SUMS.txt`。

包内不包含个人模型配置、API 密钥或对话。Windows 的 MCP 当前支持远程 Streamable HTTP；本地 stdio MCP 仅在 Linux 支持。桌面操作仍取决于应用是否提供可访问控件。
