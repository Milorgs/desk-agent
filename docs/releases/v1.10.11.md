- 聊天记录支持滚轮和 Page Up / Page Down。用户消息用蓝色实心圆，Agent 回复用白色实心圆。
- 整理了 `/` 菜单。思考计时显示在聊天记录里，思考强度显示在输入框下方。菜单编号为淡灰色，完全访问权限标为亮橙色。
- 每个对话单独保存批准模式和思考强度，重启后恢复。
- OpenAI 兼容接口和 Anthropic 的流式响应中断时，程序会停止本轮工具调用。
- Linux 下修复了 Playwright MCP 启动有窗口浏览器时缺少 X11 授权的问题。

---

- Scroll through chat history with the mouse wheel or Page Up / Page Down. User messages use a blue dot, and agent replies use a white dot.
- The `/` menu puts common actions first. The thinking timer appears in the transcript, with reasoning effort below the input box. Menu numbers are light gray, and Full access is bright orange.
- Each chat restores its approval mode and reasoning effort after restart.
- Interrupted OpenAI-compatible and Anthropic streams stop tool execution for that response.
- On Linux, Playwright MCP receives the X11 authorization needed to launch a headed browser.
